📚 Book Details Finder

📋 Project Overview

The Book Details Finder is a simple and interactive web application built using HTML, CSS, and JavaScript.
It allows users to search for any book by name and view detailed information fetched from the Google Books API.
Users can explore details such as the title, author, publisher, published date, description, and thumbnail image of each book.

🚀 Features

Search books by title or keyword
Fetch real-time data using Google Books API
Display book details such as:
Title
Author(s)
Publisher
Published date
Description
Thumbnail image
Clean, responsive, and user-friendly UI
Error handling for invalid or empty searches

🧰 Tech Stack

Frontend: HTML, CSS, EJS, Bootstrap
Backend: Node.js, Express.js
API Used: Google Books API
